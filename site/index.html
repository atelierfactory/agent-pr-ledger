agent-pr-ledger

A ledger of agent-authored pull requests. It counts; it does not score.

A read-only GitHub Action that answers one question about a repository: of the pull requests opened by coding agents (GitHub Copilot, Devin, OpenAI Codex, Cursor, Claude Code, Google Jules), how many were merged with a human review record and how many without.

Definition v1.0

OutcomeCondition
Merged with a review recordSomeone other than the PR author, and not a bot, left a review or a comment before the merge timestamp
Merged without a review recordNo such record exists
Not mergedClosed without merging

"No review record" does not mean "unreviewed". A review done inside the agent's own interface leaves no record on GitHub. The tool counts whether an auditable record exists.

Use it

permissions:
  contents: read
  pull-requests: read
steps:
  - uses: atelierfactory/agent-pr-ledger@v0.1

Nothing is sent anywhere by default. Sending aggregate counts (no repository name) is opt-in and recorded as a line in your own workflow file.

What the population looks like

Across 490 public repositories with at least five merged agent PRs (AIDev, 2024-12 to 2025-07), 41.6% merged every agent PR without a review record. The split follows posting identity, not agent brand: 1.7% of repositories where agent PRs arrive under a bot account have no records at all; 63.3% of repositories where they arrive under the developer's own account do.

Findings

One page per finding from 33,596 agent-authored pull requests: why merge rate, rework rate and self-merge rate measure conventions, what definition v1.0 measures instead, and why posting identity, not brand, is the dividing line.
